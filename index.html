    LE PRINCIPE

    Un peu de logique,
    beaucoup de possibilités.

    01

    Composez un code

    Le programme tire quatre couleurs parmi les six, avec répétitions possibles. Ce code reste fixe et caché pendant la partie.

    02

    Lisez les indices

    Bien placée : bonne couleur, bonne position. Mal placée : bonne couleur, ailleurs. Chaque occurrence compte une seule fois, les bien placées d’abord.

    03

    Affinez votre intuition

    Retrouvez les quatre positions en dix essais. Une proposition incomplète ne coûte aucun essai. Après la fin, lancez une nouvelle partie pour rejouer.

    Exemple : secret rouge, bleu, vert, jaune et proposition rouge, vert, bleu, orange → 1 bien placée, 2 mal placées. Ce secret sert uniquement à expliquer les règles.
