# Consignes de reprise

- Lire README.md et les sources du cours avant toute modification. Les règles communes et le contrat 0.2 font référence.
- Garder le même moteur pour les actions de l’interface et de l’API.
- Signaler une ambiguïté au lieu d’inventer une règle.
- Vérifier le comportement modifié et un cas valide ; lancer `npm test` et les contrôles du navigateur pour les changements du jeu.
- Rapporter l’attendu et l’obtenu. Ne jamais inventer une preuve, un essai sur téléphone, une décision personnelle ou un retour de camarade.
- Conserver des versions Git récupérables pour les changements importants. Actualiser les limites et les résultats dans le README.
- Ne publier ni conversation, ni donnée personnelle, ni clé, ni capsule vidéo.
